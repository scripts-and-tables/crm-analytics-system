Everything a CRM analyst needs, batteries included

Three independent customer outputs — activity status, value tier, and lifecycle event — derived from a transparent, well-documented set of rules.

RFMT segmentation

Recency, Frequency, Monetary (volume) and Tenure all surfaced as first-class fields, with a Diamond → Bronze tier ladder driven by AMC, AOS and order frequency.

Lifecycle events

New, Lost and Reactivated events derived from cumulative M-fields with deterministic, mutually-exclusive rules.

SQL-first pipeline

The whole calculation is one readable SQL script. No black-box framework, no proprietary DSL — just SQLite and a few CTEs anyone can audit.

Reproducible by design

Persona-driven synthetic data with a fixed RNG seed. Every clone of the repo produces the same numbers — reviewers can verify your work locally in a single command.

Filterable drill-down

Slice by activity, tier, lifecycle event or customer group. Paginated table, one-click CSV export of any filtered selection — all client-side.

Deploys as static HTML

No server, no database connection, no API. The whole dashboard ships as a JSON snapshot served from GitHub Pages — click a link, it's live.

From CSVs to a live dashboard, four steps

Each step is a single command. Re-run end-to-end in under 30 seconds.

1

Generate

Persona-driven synthetic CSVs — customers, products, transactions. 5,000 customers across 10 personas covering every CRM segment.

python scripts/generate_data/generate.py
2

Build

Apply the schema, load the CSVs, run the calculation SQL once per report month for the last 12 months and accumulate the snapshots.

python db/build.py
3

Export

Aggregate the snapshot into a small JSON payload, pre-render PNG previews and convert each markdown spec to HTML.

python scripts/build_report.py
4

Explore

Open the dashboard. Switch report months, filter customers, drill down, export a CSV — all without a server.
