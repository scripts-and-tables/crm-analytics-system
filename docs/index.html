About this project

This site is a portfolio-style showcase of a CRM analytics pipeline. Three CSV inputs (customers, products, transactions) flow through a SQL calculation layer that produces a per-customer monthly snapshot with three independent outputs:

  • Activity Status — Active / Not Active (purchases in the last 12 calendar months).
  • Value Tier — Passive (silent for ≥6 months) overrides, then Diamond → Platinum → Gold → Silver → Bronze based on Average Monthly Consumption, Average Order Size, and order frequency.
  • Lifecycle Event — New, Lost, or Reactivated in the report month.

Detailed rules live in the business-logic doc. All data on this page is generated by a seeded Python script — the same numbers reproduce on every clone.
